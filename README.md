# Proxmox Health Audit

Enterprise-focused validation and reporting toolkit for Proxmox VE environments.

## Features
- VM inventory collection
- Cluster validation
- Storage checks
- Network overview
- Migration readiness validation

## Use Cases
- Infrastructure auditing
- Migration preparation
- HA/DR validation
- Operational health checks

## Planned Features
- Automated reporting
- Snapshot validation
- Replication checks
- Storage path verification
